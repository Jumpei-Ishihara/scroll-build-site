# SPEC-04 小人がパーツを運ぶ

作成日: 2026-11-16 / ステータス: Verified(2026-11-16、テスト 75 件、幅 1280px と 375px)。工程の配分と進め方は [SPEC-05](05-自動で組み立てる.md) で置き換えた

関連: [SPEC-03 セクション固定方式](03-セクション固定方式.md)

## 1. 変更の理由

SPEC-03 では、骨組み(灰色の箱)のあと、文字や画像はその場に現れるだけで、小人は近くで動作をしているだけだった。
骨組みを用意する様子はそのまま残し、文字とパーツは小人が画面の外から運んできて、枠の中に置くようにする。

## 2. 用語

| 用語 | 意味 |
|---|---|
| パーツ | 小人が 1 回で運ぶ単位。ロゴ、見出しのひとかたまり、説明文、ボタン 1 個、画像 1 枚など。HTML では `data-part` を付けた要素 |
| 枠 | 骨組みの工程で用意される、要素の置き場。パーツを運んでいる間は、点線の枠(面を持つ要素は灰色の面)として残る |

## 3. 工程

SPEC-03 の 4 工程を次のように変える。固定の長さは画面の高さの 2.8 倍にする(運ぶ時間を取るため。S-03 を置き換える)。

| 工程 | 場面内の進み具合 | 画面に起きること | 小人の動作 |
|---|---|---|---|
| 骨組み | 0.04〜0.20 | 灰色の箱が左上から広がる(変更なし) | 引っ張る |
| 文字とパーツ | 0.22〜0.66 | パーツが 1 つずつ画面の外から運ばれ、枠の中に置かれる | 運ぶ → 置いたら手ぶらで取りに戻る |
| 色 | 0.68〜0.82 | 面、ボタン、文字に色が付く | 置く(バケツ) |
| 仕上げ | 0.84〜0.94 | 角丸と影が付く | 置く |

## 4. 要件

| ID | 要件 |
|---|---|
| P-01 | 文字とパーツは、すべて小人が運ぶ。運ばれずにその場に現れるパーツはない |
| P-02 | パーツは画面の左右どちらかの外から入る。置き場所が画面の左寄りなら左から、それ以外は右から |
| P-03 | 運んでいる間、小人はパーツの真下にいて、両手で持ち上げている。パーツと小人は同じ速さで動く |
| P-04 | パーツは、完成サイトと同じ位置に置かれる(1px 以内)。置かれたあとは動かない |
| P-05 | まだ運ばれていないパーツは表示しない |
| P-06 | パーツを置いた小人は、手ぶらで画面の外へ歩いて出て、次のパーツを持って戻る |
| P-07 | 1 人が同時に運ぶパーツは 1 つ。同時に運ばれるパーツの数は、小人の人数以下 |
| P-08 | 運んでいる間、置き場には枠が見えている |
| P-09 | 見出しは 1 文字ずつではなく、ひとかたまりずつ運ぶ(SPEC-03 S-13 を置き換える) |
| P-10 | 画像は絵が入った状態で運ぶ。色の工程では、面・ボタン・文字の色が付く |
| P-11 | 逆方向にスクロールすると、置かれたパーツが同じ道を戻って画面の外へ出る(S-14) |
| P-12 | 運ばれている途中のパーツが、ページの横スクロールを生まない(COM-40) |

## 5. テスト観点

| テスト ID | 対象 | 確認内容 |
|---|---|---|
| T-P-01 | P-01 | 全パーツが、どこかの進み具合で「運ばれている」状態になる |
| T-P-02 | P-02, P-05 | 運び始めの位置が画面の外。待機中は非表示 |
| T-P-03 | P-03, P-07 | 運んでいるパーツごとに、真下に運ぶ動作の小人が 1 人いる。同時に運ぶ数は人数以下 |
| T-P-04 | P-04 | 工程の終わりで全パーツのずれが 0。DOM 上の位置が完成サイトと一致 |
| T-P-05 | P-06 | 置いたあとの小人は歩く動作で、画面の外へ向かう |
| T-P-06 | P-08 | 運んでいる間、要素の状態は `text`(枠)で、DOM に枠の表示がある |
| T-P-07 | P-09 | 見出しのパーツが 3 つ。順に置かれる |
| T-P-08 | P-11 | 進めたあと戻すと、状態が同じ進み具合の計算結果と一致する |
| T-P-09 | P-12 | 運んでいる最中に横スクロールが出ない(デスクトップ幅とスマホ幅) |

## 6. 実装の要点

| 項目 | 内容 |
|---|---|
| パーツの動かし方 | 完成サイトの要素そのものを `transform` でずらす。置き場所からのずれを、進み具合から計算する(`src/c/state.js` の `carryOffset`) |
| 小人の位置 | パーツの下の辺の中央に手が届く位置。パーツと小人に同じ 0.2 秒の補間をかけ、ずれないようにする |
| パーツの計測 | 運んでいる途中でも正しく測れるよう、`transform` の影響を受けない `offsetLeft` / `offsetTop` を使う |
| 離れた場所への移動 | 小人が外で次のパーツを取り、反対側から入るときは、補間を切って瞬時に移す |
| 画面の外のパーツ | `#site` の `overflow: hidden` で切り取られるので、横スクロールは出ない |

実装中にテストで見つけて直した点:

- スマホ幅で、ページの最下部まで進めても「完成」にならなかった。小数の誤差で最後の場面の進み具合が 1 に届いていなかった。終わりの手前 0.5px を完成とみなすようにした
- 実績の題名と説明は箱が横いっぱいだったため、小人が文字から離れた位置に立っていた。箱を文字の幅にした
