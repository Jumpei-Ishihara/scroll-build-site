# SPEC-01 案 C「カーソルの中の人」要件

作成日: 2026-11-11 / ステータス: Draft(案 C を採用した場合に適用する)

関連: [企画書](../企画書.md) / [SPEC-00 共通要件](00-共通要件.md)

## 1. 概要

デザインツール風のキャンバス上で、名前付きカーソルがページを組み立てていく。
カーソルの下には小人がぶら下がっていて、見せ場では小人が直接パーツを動かす。最後に「公開」が押されると、ツール UI が片付いて完成サイトが残る。

- 見せたい相手: 広い層(デザインや開発の知識がない人を含む)
- 題材(仮): 架空のデザインスタジオのサイト
- 共通要件(SPEC-00)をすべて満たしたうえで、この文書の要件を追加する

## 2. 画面構成

### デスクトップ(幅 768px 以上)

| 領域 | 位置 | 内容 |
|---|---|---|
| ツールバー | 上端 | ツールのアイコン列、ファイル名、「公開」ボタン |
| レイヤーパネル | 左端 | 配置済み要素の一覧。要素が増えると行が増える |
| キャンバス | 中央 | ドットグリッドの背景と、完成サイトになるフレーム 1 枚 |
| プロパティパネル | 右端 | 選択中の要素の色、角丸、余白などの値 |
| カーソルと小人 | キャンバス上 | 名前ラベル付きカーソル 2〜3 個。それぞれに小人が 1 人ぶら下がる |

### スマホ(幅 768px 未満)

- レイヤーパネルとプロパティパネルは表示しない
- ツールバーはファイル名と「公開」ボタンだけにする
- カーソルは 1〜2 個に減らす

## 3. 段階ごとの要件

進行度の範囲は目安で、実装時に調整してよい。

| 段階 | 進行度 | 画面に起きること | 小人の動作 |
|---|---|---|---|
| 0. 空のキャンバス | 0 〜 0.08 | 空のフレーム 1 枚。カーソルが 1 つ画面外から入る | なし |
| 1. 骨組み | 0.08 〜 0.28 | ヘッダー、ヒーロー、カード 3 枚、フッターがグレーの箱として順に引かれる | 箱の角を引っ張って広げる |
| 2. 文字 | 0.28 〜 0.48 | 見出しが 1 文字ずつ入り、本文のダミー線が実際の文章に置き換わる | 見出しの文字を担いで並べる |
| 3. 色と画像 | 0.48 〜 0.68 | 配色が適用され、画像の枠に絵が入る | バケツで色を運んで流し込む |
| 4. 仕上げ | 0.68 〜 0.85 | 角丸、影、余白が整う。コメントピンが付き、解決されて消える | 水平器で位置を確認する |
| 5. 公開 | 0.85 〜 1.0 | 「公開」が押され、ツール UI が画面外へ退き、フレームが画面全体に広がる | はしごで「公開」を押し、手を振って退場 |

## 4. 機能要件

### 4.1 ツール UI

| ID | 要件 |
|---|---|
| C-01 | レイヤーパネルの行数は、キャンバスに配置済みの要素数と常に一致する |
| C-02 | カーソルが要素を操作している間、その要素に選択枠(四隅のハンドル付き)と寸法ラベルを表示する |
| C-03 | プロパティパネルの値(色、角丸、余白)は、選択中の要素の実際の見た目と一致する |
| C-04 | カーソルの名前ラベルは架空の名前とし、カーソルごとに色を変える |
| C-05 | 段階 5 で、ツールバー、両パネル、ドットグリッド、カーソルがすべて画面から消える |

### 4.2 組み立て

| ID | 要件 |
|---|---|
| C-10 | 段階 1 の箱は、完成サイトの各セクションと同じ位置・同じ大きさに収まる |
| C-11 | 段階 2 の見出しは、進行度に応じて 1 文字ずつ増える。巻き戻すと 1 文字ずつ減る |
| C-12 | 段階 3 の配色は、セクション単位で順に適用する。全体が一度に切り替わらない |
| C-13 | 段階 5 のフレームの拡大は、途切れなく完成サイトのレイアウトにつながる。切り替わりの瞬間に位置のずれやちらつきがない |

### 4.3 小人

| ID | 要件 |
|---|---|
| C-20 | 小人の動作は「ぶら下がる」「引っ張る」「運ぶ」「置く」「手を振る」の 5 種類とする |
| C-21 | 小人が直接作業する見せ場は、段階 1・2・3・5 に各 1 か所、計 4 か所とする。それ以外ではカーソルにぶら下がっているだけにする |
| C-22 | 小人の動きはスクロールに同期する。スクロールを止めると、その場で待機の動き(小さく揺れるなど)に切り替わる |
| C-23 | 巻き戻し中、小人は逆再生の動きを見せない。カーソルにぶら下がった状態に戻し、パーツだけが巻き戻る |
| C-24 | 小人は完成サイトの読みやすさを妨げない。公開完了後に残るのは、フッターの隅の 1 人だけとする |
| C-25 | 小人の大きさは、デスクトップで高さ 32〜48px、スマホで 24〜32px とする |

### 4.4 フェーズ分割

小人なしでも体験が成立することを先に確認するため、次の順で作る。

| フェーズ | 範囲 | 完了の基準 |
|---|---|---|
| 1 | 段階 0、1、5 とツール UI の骨格(小人なし) | 空のキャンバスから箱が置かれ、公開されて完成サイトに切り替わる流れが通る |
| 2 | 段階 2、3、4、レイヤーパネルとプロパティパネルの連動 | C-01 〜 C-13 を満たす |
| 3 | 小人。まず段階 5 の 1 か所、次に残り 3 か所 | C-20 〜 C-25 を満たす |
| 4 | スマホ構成、動きを減らす設定、スキップ、性能調整 | SPEC-00 の全テストが通る |

## 5. 素材

| 素材 | 形式 | 量 |
|---|---|---|
| ツール UI のアイコン | インライン SVG | 10 個程度 |
| 小人 | SVG のコマ送り。足りなければ Rive | 5 動作。1 動作あたり 4〜8 コマ |
| 完成サイトの画像 | SVG または CSS で描く図形 | ヒーロー 1 点、カード 3 点 |

## 6. テスト観点

| テスト ID | 対象 | 確認内容 |
|---|---|---|
| T-C-01 | C-01 | 進行度 0.1、0.3、0.6 で、レイヤーパネルの行数とキャンバスの要素数が一致する |
| T-C-02 | C-03 | 進行度 0.6 と 0.8 で、プロパティパネルの色と角丸の値が、選択中の要素の計算済みスタイルと一致する |
| T-C-03 | C-05 | 進行度 1 で、ツール UI の全要素が非表示である |
| T-C-04 | C-10, C-13 | 進行度 1 の各セクションの位置と大きさが、演出なしで開いた完成サイトと 1px 以内で一致する |
| T-C-05 | C-11 | 進行度を段階 2 の中で進めると見出しの文字数が単調に増え、戻すと単調に減る |
| T-C-06 | C-21, C-24 | 進行度 1 で画面に残る小人が 1 人である |
| T-C-07 | C-23 | 巻き戻し中、小人が「ぶら下がる」状態になっている |
| T-C-08 | 画面構成 | 幅 375px でレイヤーパネルとプロパティパネルが表示されない |

## 7. 範囲外

- 訪問者が自分でキャンバス上の要素を動かす編集機能
- 小人の種類や衣装の切り替え
- 複数ページの組み立て(トップページ 1 枚のみ)

## 8. 未決事項

| 項目 | 選択肢 | 仮決め |
|---|---|---|
| 小人の絵柄 | ドット絵 / 線画 / フラットなイラスト | 線画(作画量が最も少ない) |
| カーソルの人数 | 2 人 / 3 人 | デスクトップ 3 人、スマホ 1 人 |
| 巻き戻し時の小人 | ぶら下がるだけ / 片付ける動きを別に作る | ぶら下がるだけ(C-23) |
| 完成サイトの配色と書体 | 未定 | フェーズ 1 で 1 案作り、見て決める |
