# SPEC-00 共通要件

作成日: 2026-11-11 / ステータス: Draft(案は未決定。案 C・案 D+E のどちらを選んでも適用する)

関連: [企画書](../企画書.md) / [SPEC-01 案 C](01-案C-カーソルの中の人.md) / [SPEC-02 案 D+E](02-案DE-依頼コード反映.md)

## 1. 目的

スクロールに合わせて Web サイトが組み上がっていく過程を見せ、最後に普通に読める完成サイトが残る体験を作る。
この文書は、どの案を選んでも守る要件を定める。案ごとの要件は SPEC-01、SPEC-02 に分ける。

## 2. 用語

| 用語 | 意味 |
|---|---|
| 完成サイト | 演出が終わったあとに残る、通常のスクロールで読めるページ |
| 組み立て演出 | 完成サイトが出来上がるまでのスクロール連動の演出全体 |
| 段階 | 組み立て演出を区切った単位。0 から始まり、最後が「公開」 |
| 進行度 | 組み立て演出の進み具合。0(開始)〜 1(公開完了)の数値 |
| ツール UI | 演出中だけ表示される枠(案 C ではデザインツール風、案 D+E ではチャットとエディタ) |

## 3. 前提

- 実在のサービスや会社のサイトではなく、架空の題材で作るデモとする
- 静的サイトとして配信する(サーバー側の処理なし)。GitHub Pages で公開できること
- 対応ブラウザは Chrome、Safari、Firefox、Edge の最新版。スマホは iOS Safari と Android Chrome

## 4. 機能要件

### 4.1 スクロールと進行度

| ID | 要件 |
|---|---|
| COM-01 | 進行度はスクロール位置だけで決まる。同じスクロール位置では常に同じ見た目になる |
| COM-02 | 逆方向にスクロールすると、演出は進行度に従って巻き戻る |
| COM-03 | 組み立て演出の長さは、画面の高さ 5〜6 枚分のスクロール量とする |
| COM-04 | 演出中はステージを画面に固定し、公開完了後に固定を解除して完成サイトの通常スクロールに移る |
| COM-05 | 現在の段階と全体の進み具合が分かる表示(進行インジケーター)を常に出す |
| COM-06 | ページを途中のスクロール位置で再読み込みしても、その位置に対応する見た目で表示される |

### 4.2 スキップとやり直し

| ID | 要件 |
|---|---|
| COM-10 | 「完成形を見る」ボタンを演出の開始時点から表示する。押すと公開完了の位置まで移動する |
| COM-11 | 完成サイトのフッターに「もう一度組み立てる」を置く。押すとページ先頭に戻り、演出を最初から見られる |
| COM-12 | スキップとやり直しはキーボードだけで操作できる |

### 4.3 完成サイト

| ID | 要件 |
|---|---|
| COM-20 | 完成サイトの内容(見出し、本文、リンク、画像の代替テキスト)は、最初から HTML に含まれている。演出は見た目だけを変える |
| COM-21 | 完成サイトはヘッダー、ヒーロー、特徴カード 3 枚、実績または紹介、問い合わせ導線、フッターで構成する |
| COM-22 | 公開完了後、ツール UI は画面に残らず、操作の邪魔にもならない |
| COM-23 | JavaScript が無効、または読み込みに失敗した場合は、完成サイトがそのまま表示される |

### 4.4 アクセシビリティ

| ID | 要件 |
|---|---|
| COM-30 | 「動きを減らす」設定(prefers-reduced-motion)が有効な場合は、組み立て演出を行わず、完成サイトを最初から表示する |
| COM-31 | ツール UI と演出用の装飾は、スクリーンリーダーに読ませない |
| COM-32 | 完成サイトの文字と背景のコントラスト比は 4.5:1 以上とする |
| COM-33 | 演出中に 1 秒間に 3 回を超える点滅を起こさない |

### 4.5 レスポンシブ

| ID | 要件 |
|---|---|
| COM-40 | 画面幅 375px から 1920px まで、横スクロールが発生しない |
| COM-41 | 画面幅 768px 未満ではスマホ用の構成に切り替える。構成の詳細は案ごとの SPEC で定める |
| COM-42 | 画面の向きや幅を変えたとき、進行度を保ったまま見た目が正しく再計算される |

## 5. 非機能要件

| ID | 要件 |
|---|---|
| COM-50 | 演出中のアニメーションは transform と opacity を中心に組み、スクロール中に 50fps 以上を保つ(デスクトップ Chrome、一般的なノート PC で計測) |
| COM-51 | 初回読み込みで転送するファイルの合計は 1MB 以下(圧縮後)とする |
| COM-52 | 最初の表示(段階 0 の見た目)が出るまで、回線が速い環境で 2 秒以内とする |
| COM-53 | 実在するツールやサービスのロゴ、名称、UI をそのまま使わない。ツール UI はオリジナルの見た目とする |
| COM-54 | ブラウザのコンソールにエラーを出さない |

## 6. テスト観点

実装時は、次の表をもとにテストを先に書く。

| テスト ID | 対象 | 確認内容 |
|---|---|---|
| T-COM-01 | COM-01, COM-02 | 進行度 0、0.5、1 と、1 から 0.5 に戻したときで、各要素の状態が期待値と一致する |
| T-COM-02 | COM-06 | 進行度 0.5 の位置で再読み込みし、見た目が再読み込み前と一致する |
| T-COM-03 | COM-10, COM-11, COM-12 | スキップで公開完了位置に移動する。やり直しで先頭に戻る。どちらも Tab と Enter で操作できる |
| T-COM-04 | COM-20, COM-23 | JavaScript 無効で開き、完成サイトの見出しと本文がすべて見える |
| T-COM-05 | COM-22 | 公開完了後、ツール UI の要素が非表示で、クリックを受け取らない |
| T-COM-06 | COM-30 | 動きを減らす設定で開き、スクロール位置 0 で完成サイトが表示されている |
| T-COM-07 | COM-40, COM-42 | 幅 375、768、1280、1920 で横スクロールなし。演出途中で幅を変えても崩れない |
| T-COM-08 | COM-50, COM-51, COM-54 | フレームレート、転送量、コンソールエラーを計測する |

## 7. 範囲外

- 問い合わせフォームの送信処理などサーバー側の機能
- 多言語対応(日本語のみ)
- コンテンツ管理システムとの連携
- 音声、効果音
